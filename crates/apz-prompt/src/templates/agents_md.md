# AGENTS.md

## Project overview
Say what this project is, who uses it, and how the code is laid out.

## Setup and build
- Install the dependencies: `npm install`
- Build everything: `npm run build`

## Testing
- Run the whole suite before you hand work over: `npm test`
- Add a test with every fix, next to the code it covers.

## Code style
- Match the style of the surrounding code.
- Keep functions small and name them for what they do.

## Commits and pull requests
- One logical change per commit, with a message that says why.
- Open a pull request when the suite passes, and describe how you tested it.

## Security
- Keep keys and tokens in the vault, and read them from the environment at run time.
